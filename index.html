CSV Summary

Get a quick overview of any CSV file in one command.

What it does

  • Counts rows, columns and missing values
  • Numeric columns: min, max, mean, median
  • Text columns: unique values and the most common ones

Try it

python csv_summary.py sample.csv
python csv_summary.py sample.csv --top 5

Example output

File: sample.csv
Rows: 8   Columns: 5

== score ==
  filled: 6   missing: 2
  type:   numeric
  min:    68
  max:    91
  mean:   80.33
  median: 80.5
